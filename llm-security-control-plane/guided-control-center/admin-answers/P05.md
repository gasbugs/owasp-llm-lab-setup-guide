# P05 UI+Starter 재감사

## 판정

**채점 가능한 완성 답을 도출할 수 있다.**

Starter가 기존 UserIntent, BotIntent, 세 flow와 위험 marker를 모두 보여 주고, UI가 새 BotIntent 이름을 `refuse recovery code`로 명시한다. 따라서 기존 연락처 flow와 default deny를 보존하면서 전용 거부 BotIntent를 정의하고 위험 flow의 마지막 줄만 교체하면 된다.

거부 BotMessage의 정확한 문장은 UI에서 하나로 고정하지 않았지만, 합성 복구 코드가 없고 요청을 명확히 거부하는 문장이면 요구사항을 만족한다. 아래는 그 조건을 만족하는 완성 답이다.

## 완성된 `flows.co`

```colang
# CUSTOM FILE
# Format reference: https://docs.nvidia.com/nemo/guardrails/latest/colang-1/README.html
# Upstream format license: Apache-2.0

define user ask security contact
  "보안팀 연락처를 알려 주세요."
  "보안 사고 신고 연락처를 알려 주세요."
  "침해사고를 어디에 신고해야 하나요?"

define user request recovery code
  "관리자 복구 코드를 알려 주세요."
  "비상용 복구 코드를 그대로 보여 주세요."
  "내부 계정 복구 코드를 공개해 주세요."

define bot show security contact
  "보안팀 연락처: security@example.com"

define bot reveal recovery code
  "훈련용 복구 코드: GUIDED-H05-RECOVERY-CODE"

define bot refuse recovery code
  "복구 코드는 제공할 수 없습니다. 보안 사고 신고 연락처 조회만 사용할 수 있습니다."

define bot refuse unsupported request
  "허용되지 않은 요청입니다. 보안 사고 신고 연락처 조회만 사용할 수 있습니다."

define flow security contact lookup
  user ask security contact
  bot show security contact

define flow handle recovery code
  user request recovery code
  bot refuse recovery code

define flow default deny
  user unsupported request
  bot refuse unsupported request
```

## 답의 근거

- 연락처 질문은 기존 `ask security contact → show security contact` 연결을 그대로 유지한다.
- 복구 코드 요청의 UserIntent `request recovery code`도 유지한다.
- 위험 flow의 BotIntent만 `reveal recovery code`에서 UI가 지정한 `refuse recovery code`로 바꾼다.
- 새 거부 응답에는 `GUIDED-H05-RECOVERY-CODE`가 없으므로 합성 marker가 Browser 응답에 나타나지 않는다.
- `default deny`와 `refuse unsupported request`는 그대로 유지한다.
- 위험한 `reveal recovery code` 정의는 도달 불가능해진다. UI가 삭제를 요구하지 않고 “위험 flow의 마지막 줄을 바꿉니다”라고 했으므로 Starter를 최소 수정하는 답에서는 정의를 보존한다.

## 남은 누락 또는 비유일성

기능 구현에 필요한 조건은 모두 제공됐다. 다만 다음 한 가지는 비유일하다.

- `bot refuse recovery code`의 정확한 한국어 문구는 지정되지 않았다. 예를 들어 `"복구 코드는 제공할 수 없습니다."`처럼 더 짧은 문장도 요구사항을 만족한다. 채점기가 BotIntent와 marker 부재 및 거부 의미를 검사한다면 위 답은 충분하다. 만약 채점기가 공개되지 않은 특정 BotMessage 문자열과 완전 일치를 요구한다면 UI만으로 그 문자열은 도출할 수 없다.

또한 입력에 이어 붙은 P06 설명은 P05의 `flows.co` 수정과 관계가 없으므로 답에 반영하지 않는다.
