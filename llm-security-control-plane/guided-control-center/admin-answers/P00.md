# P00 UI-only 독립 풀이 감사

## 판정

**제출 답을 정확히 도출할 수 있다.**

UI는 서버가 다음 세 조건을 검사한다고 명시한다.

1. JSON 객체의 필드는 정확히 `message`와 `max_tokens` 두 개다.
2. `message` 값은 `계정 보안을 위한 조언을 한 문장으로 알려 주세요.`와 정확히 같아야 한다.
3. `max_tokens` 값은 문자열이 아닌 JSON 숫자 `64`여야 한다.

## 정확한 제출 답

`~/work/control-center-tutorial/request.json`의 전체 내용은 다음과 같다.

```json
{
  "message": "계정 보안을 위한 조언을 한 문장으로 알려 주세요.",
  "max_tokens": 64
}
```

JSON에서 객체 필드 순서는 의미가 없으므로 두 필드의 순서를 바꾼 아래 표현도 같은 답이다.

```json
{
  "max_tokens": 64,
  "message": "계정 보안을 위한 조언을 한 문장으로 알려 주세요."
}
```

공백과 줄바꿈도 JSON 의미에 영향을 주지 않는다. 핵심은 필드가 정확히 두 개이고, 문장이 정확히 일치하며, `64`에 따옴표가 없어야 한다는 점이다.

## 누락 조건

제출 payload 자체를 완성하는 데 누락된 조건은 없다.

다만 실제 HTTP 제출까지 재현하려면 화면에서 동적으로 준비되는 제출 명령과 현재 P00 전용 Token이 필요하다. 입력에는 `<pre id="tutorial-submit-command">제출 명령을 준비하고 있습니다.</pre>`만 있으므로 실제 endpoint나 Token은 도출할 수 없다. 이는 `request.json` 정답의 모호성이 아니라 전송 환경 정보의 부재다.
