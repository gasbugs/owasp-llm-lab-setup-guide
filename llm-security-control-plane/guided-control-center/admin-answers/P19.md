# P19 보강 UI+Starter 최종 재감사

## 판정

**채점 가능한 완성 답을 정확히 작성할 수 있다.**

보강된 UI는 이전에 불명확할 수 있었던 root Span과 identity 검증의 경계를 명확히 한다. 서버 수집기가 `client_ip`, `user_id`, `policy_rule`과 root Span을 먼저 대조하고, 학습자 함수에는 root를 제외한 정규화 bundle만 전달한다. 또한 대상 외 불완전 행의 제외 방식, trace ID 타입, 반복 stage 이름 허용, sequence 검증, block의 stop stage 조건이 모두 제공된다.

## 완성된 `investigation.py`

```python
"""P19 Starter: implement request-specific evidence analysis."""


def analyze_incident(bundle, request_id):
    """Join one request's normalized evidence and reject contradictions."""

    try:
        logs = bundle["logs"]
        spans = bundle["spans"]
        closures = bundle["closures"]
        downstream_calls = bundle["downstream_calls"]
    except (KeyError, TypeError) as exc:
        raise ValueError("invalid evidence bundle") from exc

    if not all(
        isinstance(collection, list)
        for collection in (logs, spans, closures, downstream_calls)
    ):
        raise ValueError("evidence collections must be lists")

    # 대상 외 행은 다른 필드가 불완전해도 request_id만 보고 제외한다.
    request_logs = [row for row in logs if row.get("request_id") == request_id]
    request_spans = [row for row in spans if row.get("request_id") == request_id]
    request_closures = [
        row for row in closures if row.get("request_id") == request_id
    ]
    request_downstream = [
        row for row in downstream_calls if row.get("request_id") == request_id
    ]

    if len(request_logs) != 1:
        raise ValueError("request must have exactly one decision log")
    if len(request_closures) != 1:
        raise ValueError("request must have exactly one closure")
    if not request_spans:
        raise ValueError("request stage spans are missing")

    log = request_logs[0]
    closure = request_closures[0]

    if not {"trace_id", "decision", "stop_stage"}.issubset(log):
        raise ValueError("decision log fields are missing")

    trace_id = log["trace_id"]
    if not isinstance(trace_id, str) or not trace_id:
        raise ValueError("trace_id must be a non-empty string")

    # 대상 request의 모든 evidence는 같은 trace에 속해야 한다.
    target_rows = request_logs + request_spans + request_closures + request_downstream
    if any(row.get("trace_id") != trace_id for row in target_rows):
        raise ValueError("target request has inconsistent trace IDs")

    decision = log["decision"]
    stop_stage = log["stop_stage"]
    if decision not in {"allow", "block"}:
        raise ValueError("decision must be allow or block")

    ordered = []
    for span in request_spans:
        if not {"stage", "sequence"}.issubset(span):
            raise ValueError("stage span fields are missing")

        stage = span["stage"]
        sequence = span["sequence"]
        if not isinstance(stage, str) or not stage:
            raise ValueError("stage must be a non-empty string")
        if isinstance(sequence, bool) or not isinstance(sequence, int):
            raise ValueError("sequence must be an integer")

        ordered.append((sequence, stage))

    ordered.sort(key=lambda item: item[0])
    sequences = [sequence for sequence, _ in ordered]
    if sequences != list(range(1, len(ordered) + 1)):
        raise ValueError("sequence must be unique and contiguous from 1")

    stages = [stage for _, stage in ordered]

    if decision == "allow":
        if stop_stage is not None:
            raise ValueError("allow decision must have a null stop_stage")
    else:
        if (
            not isinstance(stop_stage, str)
            or not stop_stage
            or stop_stage != stages[-1]
        ):
            raise ValueError("block stop_stage must equal the last stage")

    if not {"closed", "downstream_count"}.issubset(closure):
        raise ValueError("closure fields are missing")
    if closure["closed"] is not True:
        raise ValueError("request is not closed")

    downstream_count = closure["downstream_count"]
    if (
        isinstance(downstream_count, bool)
        or not isinstance(downstream_count, int)
        or downstream_count < 0
        or downstream_count != len(request_downstream)
    ):
        raise ValueError("downstream count contradicts the ledger")

    return {
        "request_id": request_id,
        "trace_id": trace_id,
        "decision": decision,
        "stages": stages,
        "stop_stage": stop_stage,
        "downstream_count": downstream_count,
    }
```

## 구현이 충족하는 조건

- 네 collection을 request ID로 먼저 거르므로 대상 외 불완전 행의 다른 필드를 보지 않는다.
- 대상 Log와 closure가 각각 정확히 한 건인지 확인한다.
- 대상 단계 Span 누락을 거부한다.
- Log에서 얻은 trace ID가 비어 있지 않은 문자열인지 확인한다.
- 대상 Log·Span·closure·downstream call의 trace ID가 모두 같은지 확인한다.
- decision을 `allow` 또는 `block`으로 제한한다.
- stage를 비어 있지 않은 문자열로, sequence를 bool이 아닌 정수로 확인한다.
- 정렬된 sequence가 정확히 `1..N`인지 비교하므로 누락과 중복을 함께 거부한다.
- stage 이름의 반복은 별도 오류로 취급하지 않는다.
- allow에는 null stop stage를 요구한다.
- block에는 sequence상 마지막 stage와 정확히 같은 stop stage를 요구한다.
- closure가 실제로 닫혔는지 확인한다.
- 기록된 downstream count가 음이 아닌 정수이며 실제 대상 호출 행 수와 같은지 확인한다.
- 차단 전 실제 호출이 있으면 그 수를 그대로 반환한다.
- 요구된 여섯 필드만 반환한다.

## 남은 누락 여부

**완성 구현을 막는 조건은 남아 있지 않다.**

입력은 각 collection의 행이 사전이라고 명시하므로, 대상 필터에서 `row.get()`을 사용할 수 있다. root Span과 identity metadata는 서버 수집기가 학습자 함수 호출 전에 검증한다고 명시됐으므로 함수에서 다시 처리하지 않는 것이 계약에 맞다.

실제 기본·역순·손상 사본 10개를 실행한 결과는 이 제한 입력만으로 확인할 수 없다. 이는 코드 계약의 누락이 아니라 빌드 후 수행할 실행 검증이다.
