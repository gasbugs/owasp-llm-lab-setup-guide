# P23 UI-only 독립 풀이 감사

## 판정

**가능**하다. UI만으로 `forward_question(message)`의 채점 가능한 완성 구현을 명확히 도출할 수 있다.

Starter에 준비된 import를 사용하고, 함수 안의 인증·`config` 골격을 유지한 채 TODO를 다음처럼 작성하면 된다.

## 완성 답

```python
"""질문을 Bedrock으로 전달하는 함수를 완성하세요."""

import boto3
from botocore.config import Config
from botocore.exceptions import BotoCoreError, ClientError


def forward_question(message):
    if not isinstance(message, str) or not message.strip():
        raise ValueError("message must not be blank")

    region_name = boto3.session.Session().region_name
    config = Config(
        connect_timeout=5,
        read_timeout=90,
        retries={"total_max_attempts": 1},
    )

    try:
        client = boto3.client(
            "bedrock-runtime",
            region_name=region_name,
            config=config,
        )
        response = client.converse(
            modelId="us.amazon.nova-lite-v1:0",
            messages=[
                {
                    "role": "user",
                    "content": [{"text": message}],
                }
            ],
            inferenceConfig={
                "maxTokens": 64,
                "temperature": 0,
            },
        )
    except (BotoCoreError, ClientError) as exc:
        raise RuntimeError("model unavailable") from exc

    return response
```

## 조건 충족 확인

- 빈 문자열과 공백 문자열은 SDK client 생성 및 `converse()` 전에 `ValueError`로 거부한다.
- 정상 입력의 원문 `message`를 변경하지 않는다.
- `boto3.client("bedrock-runtime", region_name=region_name, config=config)`로 실제 SDK 객체를 만든다.
- 지정된 Nova Lite model ID를 사용한다.
- `messages`와 `inferenceConfig`를 UI에 나온 정확한 구조로 전달한다.
- `client.converse()`를 정확히 한 번 호출한다.
- 반환된 dict를 가공하지 않고 그대로 반환한다.
- Boto3 client 생성이나 Converse 호출에서 난 SDK 예외는 정확히 `RuntimeError("model unavailable")`로 변환한다.

## 누락 조건과 경미한 해석 여지

채점 가능한 함수 구현에 필수적인 조건은 누락되지 않았다. 다음 사항은 UI가 명시하지 않았지만 세 가지 공개 채점 사례에는 영향을 주지 않는다.

- `ValueError`의 메시지 문구는 지정되지 않았다.
- 문자열이 아닌 입력의 처리는 명시되지 않았다. 위 구현은 이를 올바른 질문이 아닌 것으로 보고 `ValueError` 처리한다.
- Starter에 이미 import된 `BotoCoreError`와 `ClientError`를 SDK 오류 경계로 사용한다.
- Starter의 인증 세션과 `Config`는 함수 호출 때마다 준비되므로 전역 상태에 의존하지 않는다.
