# P02 UI + Starter 최종 독립 감사

## 판정

**가능**하다. 보강된 UI와 정확한 미완성 Starter만으로 채점 가능한 완성 답을 명확히 도출할 수 있다.

UI와 Starter가 다음 계약을 모두 제공한다.

- 정확한 함수 서명과 인증 helper 호출
- session과 bucket의 반환 방식
- `Config` 생성값
- 입력 필드·타입·길이·공백·줄바꿈 조건
- S3 client와 Bedrock Runtime client 생성 방식
- S3 key, UTF-8 원문, content type, metadata
- Titan model과 request JSON
- 호출 순서와 호출 횟수
- stream 응답 변환 및 최종 반환 구조
- 서비스 오류 전파 방식

## 전체 완성 답

```python
"""입력을 검사하고 S3 원문 저장·Titan 임베딩을 직접 연결하세요."""

import json

from aws_auth import load_aws_session
from botocore.config import Config


async def prepare_document(body, document_id, aws):
    if not isinstance(body, dict):
        raise ValueError("body must be an object")
    if set(body) != {"title", "body"}:
        raise ValueError("exactly title and body are required")

    title = body["title"]
    document_body = body["body"]

    if not isinstance(title, str):
        raise ValueError("title must be a string")
    if not 1 <= len(title) <= 120 or not title.strip():
        raise ValueError("title must contain 1 to 120 characters")
    if "\n" in title or "\r" in title:
        raise ValueError("title must not contain a line break")

    if not isinstance(document_body, str):
        raise ValueError("body must be a string")
    if not 10 <= len(document_body) <= 4000 or not document_body.strip():
        raise ValueError("body must contain 10 to 4000 characters")

    session, bucket = load_aws_session(aws)
    config = Config(
        connect_timeout=5,
        read_timeout=20,
        retries={"total_max_attempts": 1},
    )

    s3 = session.client(
        "s3",
        region_name="us-east-1",
        config=config,
    )
    runtime = session.client(
        "bedrock-runtime",
        region_name="us-east-1",
        config=config,
    )

    key = f"h02/knowledge/{document_id}.md"
    markdown = f"# {title}\n\n{document_body}\n".encode("utf-8")

    source = s3.put_object(
        Bucket=bucket,
        Key=key,
        Body=markdown,
        ContentType="text/markdown; charset=utf-8",
        Metadata={"course": "tenant-03", "activity": "h02"},
    )

    embedding_response = runtime.invoke_model(
        modelId="amazon.titan-embed-text-v2:0",
        contentType="application/json",
        accept="application/json",
        body=json.dumps(
            {
                "inputText": document_body,
                "dimensions": 1024,
                "normalize": True,
            }
        ).encode("utf-8"),
    )
    embedding = json.loads(embedding_response["body"].read())

    return {
        "source": source,
        "embedding": embedding,
    }
```

## 조건 충족 확인

- service session을 불러오기 전에 body의 자료형과 정확한 두 field를 검사한다.
- title과 본문 모두 문자열인지 확인하고 공백뿐인 값을 거부한다.
- title은 1~120자이며 CR·LF 줄바꿈을 거부한다.
- 본문은 10~4,000자다.
- 검증에는 `strip()`을 쓰지만 저장·임베딩에는 원래 문자열을 사용해 허용한 앞뒤 공백을 보존한다.
- Starter가 제공한 `session, bucket = load_aws_session(aws)`와 정확한 `Config` 값을 유지한다.
- 두 client 모두 `us-east-1`과 같은 `config`를 사용한다.
- S3 key는 서버 발급 `document_id`로 `h02/knowledge/<document_id>.md`를 만든다.
- Markdown 원문을 정확히 `# <제목>\n\n<본문>\n`로 만들고 UTF-8 bytes로 저장한다.
- `put_object()`가 반환된 다음에만 `invoke_model()`을 실행한다.
- Titan에는 가공하지 않은 원래 본문, 1024차원, normalize `true`를 전달한다.
- 두 Boto3 메서드는 동기 메서드이므로 `await`하지 않는다.
- 실제 S3 응답과 JSON decode한 embedding dict를 반환한다.
- 예외를 잡지 않으므로 S3·Bedrock·stream·JSON 오류가 그대로 전파된다.
- S3 성공 후 Titan이 실패해도 이미 저장된 원문을 삭제하지 않는다.

## 남은 누락과 경미한 해석 여지

채점 가능한 구현에 필요한 핵심 조건은 더 이상 누락되지 않았다.

- `ValueError`의 메시지 문구는 지정되지 않았으므로 다른 문구도 동작 계약을 만족한다.
- “줄바꿈”은 JSON 문자열에서 일반적으로 쓰는 `\n`, `\r`, `\r\n`을 막도록 구현했다. Unicode line separator 전체까지 막으라는 조건은 없다.
- Boto3 blob parameter에는 UTF-8 bytes를 사용했다. JSON 문자열을 그대로 전달하는 구현도 일부 SDK 환경에서 허용될 수 있지만 bytes가 명시된 UTF-8 전송을 가장 직접적으로 보장한다.
- `document_id`는 서버가 발급한다고 명시됐으므로 learner 함수에서 형식이나 path separator를 다시 검증하지 않는다.
- Bedrock response stream의 `.read()` 결과는 bytes지만 `json.loads()`가 bytes를 직접 지원하므로 별도 `.decode()`는 필요하지 않다. 명시적으로 UTF-8 decode한 뒤 파싱하는 구현도 같은 결과다.
