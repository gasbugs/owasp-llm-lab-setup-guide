# P12 UI + Starter 최종 독립 감사

## 판정

**가능**하다. 제한된 UI와 Starter만으로 채점 가능한 완성 답을 정확히 도출할 수 있다.

보강된 UI가 다음 계약을 모두 명시한다.

- 서비스 호출 순서와 모든 stage 이름
- 각 service의 인자·반환 의미와 `await` 요구
- 앞 단계 거부 및 오류 뒤의 fail-fast 동작
- 빈 검색 결과를 `retrieval_rail` 전에 중단하는 위치
- Main prompt의 정확한 JSON 직렬화식
- 성공·실패 반환 dict의 정확한 key와 text 값
- 서비스 예외를 변환하지 않고 전파하는 규칙

## 전체 완성 답

```python
"""Learner-owned P12 orchestration."""

import json


async def handle_request(request, services):
    """Connect the provided services using their actual return values."""
    authenticated = await services.authenticate(request["credential"])
    if not authenticated:
        return {"status": 401, "text": ""}

    authorized = await services.authorize(request["tenant"])
    if not authorized:
        return {"status": 403, "text": ""}

    question = await services.privacy(
        "input_privacy",
        request["message"],
    )

    input_allowed = await services.rail("input_rail", question)
    if not input_allowed:
        return {"status": 403, "text": ""}

    context = await services.retrieve(question)
    if context == "":
        return {"status": 404, "text": ""}

    retrieval_allowed = await services.rail("retrieval_rail", context)
    if not retrieval_allowed:
        return {"status": 403, "text": ""}

    prompt = json.dumps(
        {"question": question, "context": context},
        ensure_ascii=False,
        separators=(",", ":"),
    )
    answer = await services.main(prompt)

    output_allowed = await services.rail("output_rail", answer)
    if not output_allowed:
        return {"status": 403, "text": ""}

    released = await services.privacy("output_privacy", answer)
    return {"status": 200, "text": released}
```

## 조건 충족 확인

- `authenticate()`를 가장 먼저 실행하며 실패하면 401로 즉시 종료한다.
- 인증 성공 뒤 `authorize()`를 실행하며 실패하면 403으로 즉시 종료한다.
- 검색과 Main Model은 인증·인가 전에는 호출되지 않는다.
- 사용자 message를 `input_privacy`에서 처리한 실제 결과를 `input_rail`과 `retrieve()`에 전달한다.
- 입력 Rail이 거부하면 검색을 호출하지 않는다.
- 검색 결과가 정확히 빈 문자열이면 404로 중단하며 `retrieval_rail`을 호출하지 않는다.
- 검색 문서 문자열을 `retrieval_rail`에 전달하고, 거부되면 Main을 호출하지 않는다.
- Main prompt는 UI가 지정한 정확한 `json.dumps()` 식으로 만든다.
- Main 답변을 `output_rail`에 전달하고, 거부되면 `output_privacy`를 호출하지 않는다.
- 허용된 모델 답변만 `output_privacy`에 전달하며 처리된 문자열을 200 응답으로 반환한다.
- 모든 401·403·404 응답은 `text=""`를 사용한다.
- 모든 service를 `await`하며, 예외를 잡지 않으므로 service 오류가 그대로 호출자에게 전달된다.
- 이미 실행된 검색이나 다른 호출의 기록을 수정하거나 지우지 않는다.

## 남은 누락과 경미한 해석 여지

채점 가능한 핵심 구현에 필요한 조건은 누락되지 않았다.

- `request`의 field 누락이나 잘못된 타입에 대한 별도 검증은 요구되지 않았다. 직접 key 접근으로 생기는 오류는 서비스 오류와 마찬가지로 성공·거부 응답으로 숨기지 않는다.
- bool 결과 비교를 `if not value`로 할지 `if value is False`로 할지는 제공 service가 bool을 반환한다고 명시했으므로 결과가 같다.
- 변수 이름과 코드 줄바꿈은 동작에 영향을 주지 않는다.
- `context == ""`를 사용해 UI가 정의한 정확한 빈 검색 결과만 404로 처리한다. whitespace나 `None`까지 임의로 빈 결과로 확장하지 않는다.
