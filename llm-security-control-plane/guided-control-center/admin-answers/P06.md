# P06 UI + Starter 독립 풀이 감사

## 판정

**가능**하다. UI와 미완성 Starter만으로 채점 가능한 완성 답을 명확히 도출할 수 있다.

Starter는 이미 다음 동작을 구현한다.

- `action_id`를 서버 코드의 `ALLOWED_ACTIONS`와 비교한다.
- allowlist에 없는 Action은 `ACTION_DENIED`를 반환하고 Provider request를 만들기 전에 종료한다.
- 허용된 Action은 합성 Provider를 실제 호출한다.
- Provider 성공·오류를 정해진 JSON 문자열로 반환한다.

## 완성 답

```python
"""Learner-owned H06 custom Action allowlist and provider dispatch."""

from __future__ import annotations

import json
import os
import urllib.error
import urllib.request

from nemoguardrails.actions import action


ALLOWED_ACTIONS = frozenset(
    {
        "get_account_balance",
    }
)
PROVIDER_URL = os.environ["GUIDED_H06_PROVIDER_URL"].rstrip("/")
PROVIDER_TOKEN = os.environ["GUIDED_H06_PROVIDER_ACTION_TOKEN"]


def action_result(kind: str, action_id: str, **details) -> str:
    return json.dumps(
        {"kind": kind, "action_id": action_id, **details},
        ensure_ascii=False,
        sort_keys=True,
        separators=(",", ":"),
    )


@action(is_system_action=True)
async def dispatch_action(action_id: str, context: dict) -> str:
    if action_id not in ALLOWED_ACTIONS:
        return action_result("ACTION_DENIED", action_id, reason="not_allowlisted")

    payload = {
        "suite_id": context.get("suite_id"),
        "execution_id": context.get("execution_id"),
        "case_id": context.get("case_id"),
        "action_id": action_id,
        "capability": context.get("capability"),
    }
    request = urllib.request.Request(
        f"{PROVIDER_URL}/v1/actions/execute",
        data=json.dumps(payload).encode(),
        headers={
            "Authorization": f"Bearer {PROVIDER_TOKEN}",
            "Content-Type": "application/json",
        },
        method="POST",
    )
    try:
        with urllib.request.urlopen(request, timeout=5) as response:
            provider = json.loads(response.read())
    except urllib.error.HTTPError as error:
        try:
            detail = json.loads(error.read()).get("detail", "provider rejected action")
        except (UnicodeDecodeError, json.JSONDecodeError):
            detail = "provider rejected action"
        return action_result(
            "ACTION_PROVIDER_ERR", action_id, status_code=error.code, detail=detail
        )
    except (OSError, TimeoutError, json.JSONDecodeError) as error:
        return action_result("ACTION_PROVIDER_ERR", action_id, detail=type(error).__name__)

    return action_result(
        "ACTION_OK",
        action_id,
        provider_call_id=provider["provider_call_id"],
        balance_before=provider["balance_before"],
        balance_after=provider["balance_after"],
        effect_id=provider["effect_id"],
    )
```

## 조건 충족 확인

- `get_account_balance`는 allowlist에 있으므로 기존 Provider 호출 경로를 실행한다.
- `transfer_training_funds`와 `get_account_balance_and_transfer`는 allowlist에서 제거되어 Provider request 생성 전에 반환된다.
- 그 밖의 지원하지 않는 Action도 같은 검사에서 거부된다.
- allowlist는 module의 불변 `frozenset`이며 `context`나 사용자 문장에서 값을 추가하지 않는다.
- 정상 조회까지 막는 빈 allowlist가 아니므로 정상 Provider 호출을 유지한다.
- 거부를 응답 문구로만 위장하지 않고 `urlopen()`보다 앞에서 실행을 끝낸다.

## 남은 누락과 해석 여지

채점 가능한 구현에 필요한 조건은 누락되지 않았다.

UI에는 구체적인 채점 요청과 기대 JSON이 없지만 Starter가 거부 결과 형식과 Provider payload를 이미 완성해 두었고 TODO가 수정 범위를 allowlist 상수로 한정한다. 따라서 이를 알 필요가 없다.

다음은 동작에 영향을 주지 않는 표현상 대안이다.

```python
ALLOWED_ACTIONS = frozenset({"get_account_balance"})
```

또는

```python
ALLOWED_ACTIONS = frozenset(("get_account_balance",))
```

둘 다 같은 단일 원소 불변 집합을 만든다. 기존 여러 줄 형식을 유지한 첫 번째 완성 답이 Starter에서 가장 작은 수정이다.
