# P21 UI + Starter 독립 풀이 감사

## 판정

**가능**하다. UI와 미완성 Starter만으로 채점 가능한 완성 답을 명확히 도출할 수 있다.

Starter가 다음 핵심 계약을 모두 제공한다.

- 정책 principal: `support-agent`
- 허용 모델: `us.amazon.nova-lite-v1:0`
- 허용 MCP Server: `training-notice-mcp`
- 허용 Tool: `lookup_notice`, `oversized_context`, `slow_context`
- 서버 상한: Tool 2회, 결과 160 bytes, timeout 250 ms
- 거부 예외: `PolicyDenied`
- 반환형: `Admission`
- state owner는 반환 필드가 아니라 admission 전에 검증할 경계

UI의 “한도를 넘는 요청은 뒤쪽 서비스에 닿기 전에 멈춰야 한다”에 따라 요청값이 각 정책 상한보다 크면 `PolicyDenied`를 발생시킨다. 허용된 요청의 반환값에는 요청값이 아닌 정책값을 사용한다.

## 완성 답

```python
"""Learner-owned Agent Gateway admission policy for H21."""

from __future__ import annotations

from dataclasses import dataclass


class PolicyDenied(ValueError):
    """Stop before the model provider or MCP server is contacted."""


@dataclass(frozen=True)
class Admission:
    principal: str
    model: str
    server_id: str
    tool: str
    max_tool_calls: int
    max_result_bytes: int
    tool_timeout_ms: int


POLICIES = {
    "support-agent": {
        "models": {"us.amazon.nova-lite-v1:0"},
        "servers": {"training-notice-mcp"},
        "tools": {"lookup_notice", "oversized_context", "slow_context"},
        "max_tool_calls": 2,
        "max_result_bytes": 160,
        "tool_timeout_ms": 250,
    }
}


def authorize(
    principal: str,
    model: str,
    server_id: str,
    tool: str,
    requested_tool_calls: int,
    requested_result_bytes: int,
    requested_timeout_ms: int,
    state_owner: str,
) -> Admission:
    """Return server-owned limits after validating every Agent boundary."""
    configured = POLICIES.get(principal)
    if configured is None:
        raise PolicyDenied("principal is not allowed")

    if model not in configured["models"]:
        raise PolicyDenied("model is not allowed")
    if server_id not in configured["servers"]:
        raise PolicyDenied("server is not allowed")
    if tool not in configured["tools"]:
        raise PolicyDenied("tool is not allowed")
    if state_owner != principal:
        raise PolicyDenied("state owner does not match principal")

    return Admission(
        principal=principal,
        model=model,
        server_id=server_id,
        tool=tool,
        max_tool_calls=configured["max_tool_calls"],
        max_result_bytes=configured["max_result_bytes"],
        tool_timeout_ms=configured["tool_timeout_ms"],
    )
```

## 조건 충족 확인

- 알 수 없는 principal은 raw `KeyError` 대신 정책 거부로 처리된다.
- 모델, Server, Tool을 각각 서버 소유 set과 대조한다.
- `state_owner == principal`을 강제하며 client의 owner 주장을 그대로 신뢰하지 않는다.
- 세 requested limit가 정책값을 넘으면 Provider/MCP 실행 전에 `PolicyDenied`가 발생한다.
- 승인된 반환값에는 request의 limit가 아니라 `POLICIES`의 2·160·250이 들어간다.
- 모델·Server·Tool은 allowlist를 통과한 실제 제안값을 유지하므로 정상 제안→Tool→최종 응답 경로를 실행할 수 있다.
- OAuth audience·scope는 이 함수의 인자나 `Admission`에 없으므로 UI 설명대로 MCP Server의 추가 검사 범위로 남긴다.

## 남은 누락과 경미한 해석 여지

핵심 채점 구현에 필요한 값과 계약은 모두 제공된다. 다음 경계는 UI가 명시하지 않았다.

- requested limit가 0 또는 음수일 때 거부할지 여부
- requested limit가 `bool`, 문자열, 실수일 때의 처리
- 요청값이 정책보다 작을 때도 정책 최대값을 반환할지, 더 작은 요청값을 존중할지
- `PolicyDenied`의 정확한 메시지
- model·server·tool·owner의 비문자열이나 빈 문자열 처리
- Server와 Tool을 독립 allowlist로 검사할지 `(server_id, tool)` 조합으로 검사할지

현재 Starter에는 한 Server만 있으므로 독립 검사와 조합 검사의 결과가 같다. UI가 “반환값 ... 요청값이 아니라 정책값”이라고 명시하므로 요청값이 정책 이하일 때도 고정 정책값을 반환하는 해석이 가장 직접적이다.

0·음수와 잘못된 타입까지 방어하려면 각 requested limit에 `type(value) is int and value >= 0` 또는 `>= 1` 검사를 추가할 수 있다. 그러나 최소 허용값을 UI가 정하지 않았고 아홉 채점 사례의 경계도 공개하지 않았으므로 위 완성 답은 명시된 “상한 초과”만 거부한다. 이 누락은 공개된 핵심 채점 계약을 구현하는 데 장애가 되지 않는다.
