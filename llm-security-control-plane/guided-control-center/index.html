INSTRUCTOR-LED

Starter는 512 Token 요청을 그대로 보내므로 첫 검증은 HIT가 정상입니다. 이 화면은 강사와 함께 진행하는 본 실습이므로 아래 코드를 그대로 작성해 작은 요청은 유지하고 큰 요청은 128 이하로 제한합니다.

비용 안내연결 확인은 1회, 현재 구현 검증은 정상·위험 2회의 Nova Lite 요청을 새로 만듭니다.

LEARNER-OWNED APPLICATION

고객 상담 앱에 출력 상한 구현하기

llm-security-control-plane/guided-labs/h01-nova-output-limit/policy.py의 반환 줄을 다음과 같이 작성합니다. min은 요청값과 128 중 작은 값을 고르므로 64는 유지하고 512는 128로 줄입니다.

def apply_output_limit(requested_max_tokens: int) -> int:
    return min(requested_max_tokens, 128)

파일을 저장한 뒤 수강생 앱을 다시 Build하고 실행 서비스에 연결합니다.

docker compose \
  --env-file llm-security-control-plane/.state/guided-course.env \
  --file examples/security-monitoring/compose.guided.yaml \
  build guided-student-app
docker compose \
  --env-file llm-security-control-plane/.state/guided-course.env \
  --file examples/security-monitoring/compose.guided.yaml \
  up -d --no-deps --force-recreate guided-student-app
