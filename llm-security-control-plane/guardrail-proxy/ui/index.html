실제 호출

정상·위험 요청을 시험합니다

이 버튼은 실제 NeMo·Presidio와 Bedrock을 호출하며 사용량이 발생합니다.

검색·도구 예시는 서버가 보유한 고정 fixture를 사용합니다. 도구 검증은 서버 경계이며 결과 본문은 NeMo 검색 Action으로 검사합니다. Main이 호출되면 Bedrock 사용량이 발생합니다.
